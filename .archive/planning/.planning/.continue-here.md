## Context & Mental Model

**Memoria's Position in Market:**

The note-taking market is split between cloud-first (Notion, OneNote - collaboration) and local-first (Obsidian, Logseq - control). Memoria takes the local-first approach but differentiates with:

1. **Tree navigation excellence** - Unlike Obsidian (search-first), Memoria makes folder structure a first-class navigation method
2. **Multi-tab editing** - Like VSCode, allows comparing/editing multiple notes simultaneously (most apps don't do this well)
3. **Simplicity** - No database, no plugins, no vault configuration; just "choose folder, work"
4. **Responsive mobile** - Designed mobile-first from start (most note apps are desktop-first)
5. **Unix aesthetic** - Dark theme, minimalista, vim/nano vibes (appeals to technical users)

**Why This Matters:**

Gap identified: Users want Obsidian's power but simpler UX, or Bear's simplicity but with linking. Memoria = middle ground with tree + search + links + multi-tab, without configuration burden.

**Build Strategy:**

Quick 4-phase MVP delivery:
- Phase 1: Plumbing (file system + tree UI)
- Phase 2: Core experience (editor + tabs)
- Phase 3: Knowledge connections (search + links)
- Phase 4: Polish (UX refinement + performance)

Each phase: Plan → Execute → Verify → Next

**Tech Approach:**

Vanilla JS + HTML5 + CSS3 (no frameworks) to keep it simple, portable, lightweight. File System Access API for local files (modern browsers). localStorage for settings.
