## Mental Context

**Vision:** Memoria is a minimalist, local-first Markdown note manager positioned between Obsidian (powerful but complex) and Bear (simple but limited). Key differentiator: tree-first navigation + multi-tab editing + simple UX.

**Phase 1 is critical** because it establishes:
- How we interact with the file system (File System Access API)
- How we represent files/folders in memory (Tree/Node classes)
- How we render tree UI (expandable, responsive)
- Foundation for all future phases (editor, search, links)

**Why this split (Wave 1 & 2)?**
- Wave 1 = data layer only (testable independently, solid foundation)
- Wave 2 = user interactions (depends on Wave 1, adds complexity)
- Allows parallel learning: one person does Wave 1, another plans Wave 2

**Quality bar:** No console errors, responsive design, graceful error handling, <100ms tree render for 500 files.
